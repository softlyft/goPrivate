# Roadmap

High-level direction only. Details live in RFCs and issues.

```
Browser MVP
    ↓
Protocol Stabilization
    ↓
Security Audit
    ↓
Native Clients
    ↓
Federation
    ↓
Foundation
```

| Stage | Intent |
| ----- | ------ |
| **Browser MVP** | Reference client + reference relay; end-to-end encrypted 1:1 ephemeral chat |
| **Protocol Stabilization** | Documented wire format, RFCs, versioning, independent implementability |
| **Security Audit** | External review of crypto, handshake (TOFU), relay threat surface |
| **Native Clients** | Additional reference clients beyond the web app |
| **Federation** | Interoperability across independently operated relays (design TBD) |
| **Foundation** | Long-term stewardship / institutional home if the community warrants it |

No premium features. No enterprise edition. The project remains fully open source (AGPLv3).
