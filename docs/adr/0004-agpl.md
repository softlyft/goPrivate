# ADR 0004: AGPLv3 license

## Context

The project is an open protocol with hosted reference deployments. Proprietary closed forks of hosted code would undermine the commons.

## Decision

License the repository under **GNU Affero General Public License v3.0 (AGPLv3)**.

## Consequences

- Network use triggers source disclosure obligations for modified versions
- Encourages self-hosting and contribution of improvements
- Some companies may avoid AGPL; that is an accepted tradeoff
