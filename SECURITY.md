# Security policy

## Supported versions

Security fixes are applied to the default branch of this repository. Please update to the latest commit or release when advisories are published.

## Reporting a vulnerability

**Do not open a public issue for security vulnerabilities.**

Please report via GitHub Security Advisories for this repository:

https://github.com/softlyft/goPrivate/security/advisories/new

If that is unavailable, contact a maintainer listed in [`governance/MAINTAINERS.md`](./governance/MAINTAINERS.md) privately.

Include:

- Description of the issue
- Steps to reproduce
- Affected component (protocol, reference relay, reference client, crypto)
- Impact assessment if known

We will acknowledge receipt as soon as practical and coordinate disclosure.

## Scope notes

Please read [`docs/threat-model.md`](./docs/threat-model.md). Reports that rely solely on threats we explicitly do not claim to prevent (e.g. shoulder surfing, malware) may be closed as out of scope — still appreciated if they reveal unexpected severity.
